# Chronic Kidney Disease Prediction Using Machine Learning

## Project Overview
This project focuses on predicting Chronic Kidney Disease (CKD) using Machine Learning classification algorithms. The dataset contains patient health information that is used to build predictive models.

## Dataset Information
- Dataset: Chronic Kidney Disease Dataset
- Total Records: 400
- Total Features: 26
- Target Column: `classification`
- Prediction: CKD or Not CKD

## Machine Learning Algorithms
1. Logistic Regression
